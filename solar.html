07RED FLAGS — NEVER IGNORE
⚡
PV 30–40% low on a clear sunny day
Seeing ~13 kWh when expecting 21+ kWh — one 5-panel string may have disconnected.
→ Check inverter LCD for DC fault. Call contractor same day.
🔋
Battery SOC stuck flat for hours in daytime
Charging stopped — BMS or inverter fault.
→ Screenshot fault code. Call contractor.
📈
Grid import > 3 kWh/day for 2+ weeks
Load higher than modeled or generation underperforming.
→ Review habits first. If normal, call contractor.
📡
"Communication Lost" on dongle
WiFi dropped or dongle hardware issue.
→ Restart dongle. Check WiFi signal near inverter.
🌡
Battery over-temperature alert
SE15B too hot — needs ventilated, shaded indoor space.
→ Check battery placement immediately.
🚨
Any red fault banner in SolarMan
System fault — do not dismiss.
→ Screenshot + send to contractor immediately.
